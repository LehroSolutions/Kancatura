# Lehro Solutions Brand Reference

## Brand Colors

| Color | Hex | Usage |
|-------|-----|-------|
| Primary Dark | `#0A0A0F` | Backgrounds, depth |
| Primary Blue | `#2563EB` | CTAs, links, accents |
| Accent Cyan | `#06B6D4` | Gradients, highlights |
| Accent Purple | `#7C3AED` | Creative/tech posts |
| Accent Mint | `#10B981` | Success/growth posts |
| Surface Light | `#18181B` | Cards, panels |
| Text Primary | `#FAFAFA` | Headlines, body on dark |
| Text Secondary | `#A1A1AA` | Subtext, captions |
| Border Light | `#27272A` | Dividers, cards |

## Typography

- **Headlines:** Bold/Extra Bold, clean sans-serif (Inter, system-ui)
- **Body:** Regular/Medium, readable
- **Accents:** Monospace for tech/code references (JetBrains Mono, system mono)

## Logo

- Primary wordmark: **"Lehro Solutions"**
- Short form: **"LehroForge"** (product), **"LehroCode"** (tool)
- No external logo file yet — use text-based treatment

## Voice & Tone

- Tech-forward but accessible
- Confident, expert — never arrogant
- Action-oriented language
- Avoid buzzwords ("synergy", "leverage", "paradigm") — be clear and specific

## Brand Taglines

- Primary: *"AI Agent Orchestration"*
- LehroForge: *"API Orchestration, Open Source"*
- Secondary: *"Integrate anything. Ship everything."*

## Design Principles

1. **Dark-first:** All posters default to dark backgrounds
2. **Blue anchor:** Accent with primary blue (#2563EB) at minimum
3. **Space is breath:** Generous padding, never crowded
4. **Hierarchy by size and weight,** not color alone
5. **Readable at small sizes:** TikTok thumbnails are tiny — big type wins
